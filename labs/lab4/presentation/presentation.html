Цель работы

Построить математическую модель гармонического осциллятора.

Задание

  1. Колебания гармонического осциллятора без затуханий и без действий внешней силы $$\ddot{x} +3.5x = 0,$$

  2. Колебания гармонического осциллятора c затуханием и без действий внешней силы

$$\ddot x + 11 \dot x + 11 x = 0,$$

  1. Колебания гармонического осциллятора c затуханием и под действием внешней силы

    $$\ddot x + 12 \dot x + x = 2 cos(0.5t).$$ На интервале t ∈ [0;51] (шаг 0.05) с начальными условиями x0 = 0, y0 =  − 1.2.

Выполнение лабораторной работы

julia> using DifferentialEquations, Plots;
julia> tspan = (0, 51)
julia> u0 = [0, -1.2]
julia> p1 = [0, 3.5]
julia> function f1(u, p, t)
       x, y = u
       g, w = p
       dx = y
       dy = -g .*y - w^2 .*x
       return [dx, dy]
       end
julia> problem1 = ODEProblem(f1, u0, tspan, p1)
julia> sol1 = solve(problem1, Tsit5(), saveat = 0.05)

julia> plot(sol1, title = "Модель гармонического осциллятора без затуханий и действий внешней среды", label = "Зависимость x от y", xaxis = "x", yaxis = "y")

julia> plot(sol1, idxs=(1, 2), title = "Фазовый портрет", label = "Зависимость x от y", xaxis = "x", yaxis = "y")
